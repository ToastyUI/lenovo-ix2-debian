# Security policy

This experimental community project provides ix2-ng build scripts and examples.
It does not promise a security support period or response SLA. Debian, Linux,
Samba and other dependencies have their own security support policies.

For a suspected vulnerability, use GitHub private vulnerability reporting if
available on this repository. Otherwise open an issue requesting a private
contact channel without including exploit details, credentials or personal data.
Do not post secrets or sensitive device dumps in public issues.

Before sharing logs, remove keys, credentials, MACs, serial numbers, RAID UUIDs,
private hostnames, network topology and personal paths. Do not upload rootfs,
initramfs or disk images containing authorized_keys, SSH host keys or user data.

Kernel C trades hardening for performance; keep experimental NAS services on a
restricted network. Review access controls and upstream updates yourself.
