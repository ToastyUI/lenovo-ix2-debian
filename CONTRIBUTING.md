# Contributing

Open an issue or pull request describing the ix2 model, the change and how it was
checked. Use documentation-only addresses and synthetic identifiers in examples.
Never attach private device configuration or personalized binary images.

Keep third-party credits and licenses intact. Changes to boot or storage scripts
need an explicit description of effects on existing data and recovery.
Run `bash -n` on changed shell scripts; do not run hardware scripts on your laptop.
Contributions of original project code are submitted under the repository MIT
license; third-party material retains its upstream license.
